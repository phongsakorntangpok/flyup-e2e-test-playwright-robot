## 4. การลบข้อมูลทดสอบ (Post-condition ของทุก Test Case)

ระบบจำกัดแบบร่างไม่เกิน 5 โปรเจกต์ ทุก Test Case จึงลบโปรเจกต์ที่ตัวเองสร้างเมื่อจบ ทั้งกรณีผ่านและไม่ผ่าน

1. ก่อนเริ่มเทสต์ เก็บ snapshot รายการโปรเจกต์ของบัญชีไว้
2. หลังจบเทสต์ ลบโปรเจกต์ตาม id ที่เทสต์บันทึกไว้ และโปรเจกต์สถานะ DRAFT / PENDING_REVIEW ใหม่ที่ไม่อยู่ใน snapshot
3. ถ้าโปรเจกต์อยู่ในสถานะ PENDING_REVIEW (TC-14-015) ถอนคำขอให้กลับเป็น DRAFT ก่อน
4. ลบ FAQ → Milestone → Story / Media → โปรเจกต์ แล้วตรวจซ้ำว่าโปรเจกต์ถูกลบจริง ถ้าลบไม่สำเร็จเทสต์จะ fail
5. แบบร่างเดิมของบัญชีไม่ถูกลบ
